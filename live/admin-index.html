Admin — How to add data

No login needed

Everything is edited in your Google Sheet

There's no separate admin login — you (and anyone you trust) just type competitions, events, competitors and times straight into the spreadsheet, like Excel. The public live pages read from it automatically and refresh every 10–20 seconds.

Open the Google Sheet ↗

Your sheet needs 5 tabs, named exactly as below. First row of each tab = the column headers shown here.

1. Competitions

One row per competition.

idnamevenuestartDateendDate
isr2026Israel Championship 2026Tel Aviv, Israel2026-08-252026-08-27

id is anything unique you make up (no spaces) — it's what goes in the page link.
startDate/endDate format: YYYY-MM-DD.

2. Events

One row per event, per competition.

compIdeventIdnameorder
isr20263333x3x3 Cube1
isr20262222x2x2 Cube2

compId must match a row in the Competitions tab. order controls the sidebar order (1, 2, 3…).

Valid eventId codes: 333, 222, 444, 555, 666, 777, 333bf, 333oh, clock, minx, pyram, skewb, sq1, 333fm, 444bf, 555bf.

3. Rounds

One row per round of an event — this drives the schedule.

compIdeventIdroundIdnameformatscheduledDatestartTimeendTimeorder
isr2026333r1First Roundao52026-08-2510:0011:001
isr2026333finalFinalao52026-08-2615:0016:002

roundId: anything unique within that event. Valid format codes: ao5, mo3, bo3, bo1, fmc-mo3.

4. Competitors

One row per person registered for a competition.

compIdcompetitorIdnamecountrywcaId
isr2026c1Dylan MillerUnited States2019MILL01

competitorId: anything unique. wcaId is optional, leave blank if unknown.

5. Results

This is where you type times as the competition runs. One row per competitor, per round.

compIdeventIdroundIdcompetitorIda1a2a3a4a5
isr2026333r1c112.34DNF11.0213.5010.88

Times: seconds with 2 decimals, e.g. 12.34. Use DNF or DNS where needed.
FMC (333fm): just the move count, e.g. 24.
Leave unused attempt columns blank for Bo1/Bo3/Mo3 rounds.

One-time setup checklist

  1. Create the 5 tabs above in your Google Sheet with those exact names and headers.
  2. Share the sheet: Share → General access → Anyone with the link → Viewer.
  3. Copy the Sheet ID from its URL and paste it into assets/config.js in this live folder.
  4. Upload the live folder to your hosting. Done — the site reads the sheet live.
