🔄 Backup & Device Sync

There's no real account/login system here — that needs a live server with a database, which a single static HTML file can't provide honestly. What actually works fully offline: a complete backup of every event, session, setting, achievement and trainer stat as one file, plus a copy-paste code to move everything to another device by hand.

Restoring a full backup replaces everything currently on this device.
